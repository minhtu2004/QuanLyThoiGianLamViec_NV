# QuanLyThoiGianLamViec_NV
# Hệ Thống Quản Lý Thời Gian Làm Việc Của Nhân Viên (C++)

Môn học Lập trình Hướng đối tượng (OOP).

## Chức năng
* Quản lý nhân viên Full-time (FT) và Part-time (PT).
* Chấm công tự động theo giờ hệ thống / nhập thủ công (dùng để test).
* Tính tăng ca (OT), thời gian làm việc mỗi ngày.
* Đọc/Ghi dữ liệu ra file CSV.
* Cập nhật ngày mới, dữ liệu từng ngày trong tháng được lưu lại.
* Xóa/thêm/chỉnh sửa thông tin nhân viên.

## Ngôn ngữ sử dụng
* Ngôn ngữ: C++
* Kỹ thuật: OOP (Kế thừa, Đa hình), Vector, File I/O.
